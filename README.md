# Student Grade Calculator

## Описание проекта

Student Grade Calculator — это небольшое приложение на Python, которое рассчитывает успеваемость студента.

Программа умеет:

- вычислять средний балл по списку оценок;
- определять буквенную оценку (A, B, C, D, F);
- определять, сдал студент или нет (порог — 60 баллов).

Проект выполнен в рамках СОӨЖ по предмету «Прикладные аспекты DevOps» (Вариант №17).

## Цель проекта

Показать базовые DevOps-практики на простом примере:

- написать программу на Python;
- покрыть её автоматическими unit-тестами;
- хранить код в Git и GitHub;
- настроить автоматический запуск тестов при каждом изменении кода (CI) с помощью GitHub Actions.

## Используемые технологии

- **Python** — язык программирования
- **pytest** — библиотека для написания и запуска тестов
- **Git** — система контроля версий
- **GitHub** — хранение репозитория в интернете
- **GitHub Actions** — автоматический запуск проверок (CI)

### Функции в `src/grade_calculator.py`

| Функция | Что делает |
|---|---|
| `calculate_average(grades)` | Считает средний балл. Если список пустой или оценка не в диапазоне 0–100 — ошибка `ValueError` |
| `get_letter_grade(score)` | Возвращает букву: 90–100 → A, 80–89 → B, 70–79 → C, 60–69 → D, 0–59 → F |
| `is_passed(score)` | Возвращает `True`, если балл 60 и выше, иначе `False` |

## Установка

1. Скачать проект:

```bash
git clone <адрес-репозитория>
cd student-grade-calculator
```

2. Создать и активировать виртуальное окружение (рекомендуется, на macOS с Homebrew — обязательно):

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установить зависимости:

```bash
python3 -m pip install -r requirements.txt
```

## Запуск программы

```bash
python3 main.py
```

Пример вывода:

```
=== Расчёт успеваемости студента ===

Студент: Aigerim
Оценки: [85, 90, 78, 92]
Средний балл: 86.25
Буквенная оценка: B
Результат: Сдал
```

## Запуск тестов

```bash
python3 -m pytest -v
```

Тесты проверяют:

1. правильное вычисление среднего балла;
2. получение оценки A;
3. получение оценки B;
4. получение оценки F;
5. студент с баллом выше 60 сдаёт;
6. студент с баллом ниже 60 не сдаёт;
7. пустой список оценок вызывает `ValueError`;
8. оценка больше 100 вызывает `ValueError`;
9. отрицательный балл вызывает `ValueError`.

## CI/CD

**CI (Continuous Integration — непрерывная интеграция)** — это практика, когда после каждого изменения кода он автоматически проверяется: запускается программа и тесты. Так ошибки находятся сразу, а не в конце работы.

В этом проекте CI настроен с помощью GitHub Actions в файле `.github/workflows/ci.yml`.

## Как работает GitHub Actions

GitHub Actions автоматически запускается, когда:

- в репозиторий отправляется код (`push`);
- создаётся запрос на слияние (`pull_request`).

GitHub запускает виртуальную машину с Ubuntu (`ubuntu-latest`) и выполняет шаги по порядку:

```
Checkout repository   → скачивает код репозитория
        ↓
Setup Python          → устанавливает Python 3.12
        ↓
Install dependencies  → устанавливает pytest из requirements.txt
        ↓
Application check     → запускает python main.py
        ↓
Run tests             → запускает pytest -v
```

Если все шаги прошли успешно — во вкладке **Actions** на GitHub появляется зелёная галочка ✅.
Если какой-то тест упал — красный крестик ❌, и сразу видно, где ошибка.
